## 제작 시 반드시 지킬 것

- 승인 샘플과 일관된 금발 여성과 검은 머리 남성, 동일한 색감과 섬세한 작화를 유지합니다.
- 한 번에 한 페이지씩 세로 인쇄형 만화로 생성합니다. 여러 페이지를 한 장으로 묶는 합본 이미지는 사용하지 않습니다.
- 한국어 말풍선, 자연스러운 상황극, 다양한 크기의 컷, 검은 테두리와 페이지 번호를 유지합니다.
- PPT, 카드뉴스, 설명 상자 나열, 일본어 대사로 대체하지 않습니다.
- 원본 PDF의 정보를 페이지별 반영표로 검증하며 합격하지 않은 이미지는 정식 완료로 세지 않습니다.

> 이 세 참조 이미지가 있다는 사실이 56쪽 만화 완성을 뜻하지 않습니다. 제작·식자·PDF 검수는 별도의 작업입니다.
